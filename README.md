# ScummVM

### Play classic point-and-click adventures on modern hardware

ScummVM is a program that reimplements the scripting engines of classic adventure games, letting you play LucasArts, Sierra, and hundreds of other classic games on modern hardware with improved functionality.

<br>

---

## Features

| | |
|:---|:---|
| **250+ Games** | Support for classic adventures from LucasArts, Sierra, Humongous, and more |
| **Save Anywhere** | Save and load at any point in games that didn't originally support it |
| **Enhanced Audio** | MT-32 emulation and improved music for games that support it |
| **Cross-Platform** | Windows, macOS, Linux, Android, iOS, and even gaming consoles |
